## 二、到货后先检查

收到快递后，先别急着组装，花 5 分钟检查：

1. **ESP32-S3 板子**：看有没有明显划痕、芯片有没有裂、USB 口有没有歪
2. **LED 灯环**：数一下灯珠数量是不是 20 颗，看焊盘有没有氧化发黑
3. **编码器**：转一下，应该有"咔哒咔哒"的段落感；按一下，应该有明确的按键手感
4. **电阻电容**：包装有没有破，引脚有没有弯折
5. **USB-C 线**：插上手机和电脑，确认能传数据（不只是充电）

## 三、认识这些零件（小白扫盲）

### ESP32-S3 开发板

板子上有两排金属针脚（GPIO），每个针脚旁边都印有编号。你需要找到这些：

- **5V** 或 **VBUS**：输出 5V 电
- **GND**：接地（负极），通常有多个
- **3V3** 或 **3.3V**：输出 3.3V 电
- **GPIO 编号**：比如 GPIO1、GPIO2、GPIO18 等，是可编程控制的针脚

板子上有一个 **Type-C 口**，用于连接电脑供电和传输数据。

### WS2813 LED 灯环

灯环上有 3 根线（或 3 个焊盘）：

- **5V** 或 **VCC**：接 5V 正极
- **GND** 或 **DIN** 旁边的 **GND**：接地
- **DIN** 或 **Data In**：数据输入线

有些灯环还有 **DOUT**（数据输出），用于串联下一个灯环，这次用不到。

### 旋转编码器（EC11）

底部有 5 个金属引脚，分两排：

- 一排 3 个引脚：中间的是 **Common（公共端）**，两边是 **A相** 和 **B相**
- 一排 2 个引脚：是 **按键开关** 的两个脚

### SN74AHCT125 芯片

黑色小芯片，14 个引脚（DIP-14）。引脚编号从缺口/圆点左侧开始逆时针数：1-7 一边，8-14 另一边。

- **VCC**（引脚14）：接 5V
- **GND**（引脚7）：接地
- **1A**（引脚2）：数据输入
- **1Y**（引脚3）：数据输出
- **1OE**（引脚1）：输出使能（低电平有效）

## 四、组装步骤（手把手）

### 准备工作

1. 找一个干净、明亮、绝缘的桌面（木桌或塑料桌，**不要在金属桌上操作**）
2. 把所有零件摆开，对照清单检查一遍
3. 手摸一下金属水龙头或暖气片，放掉身上的静电
4. **整个组装过程不要插任何电源**

### Step 1：把电阻焊到/插到灯环数据线上

LED 灯环的数据输入（DIN）需要串联一个 **330Ω 电阻** 来保护。

**方法A：用面包板（不用焊接，推荐小白）**
1. 把 330Ω 电阻的两条腿分别插到面包板的两个不相邻的孔里
2. 用一根杜邦线（公对母）的"母头"插到电阻一端的同一排孔
3. 这根杜邦线的"公头"等下插到 ESP32-S3
4. 电阻另一端的同一排孔插另一根杜邦线，公头等下接到 74AHCT125 的输出

**方法B：直接焊接（更牢固）**
1. 剪一小段热缩管套到灯环 DIN 线上
2. 把 330Ω 电阻一端焊到 DIN 线上
3. 电阻另一端焊一根杜邦线（剪掉一头，露出铜丝）
4. 热缩管套住焊点，用打火机或烙铁加热收缩

### Step 2：给灯环接上电源滤波电容

1. 找到 **1000µF 电解电容**（圆柱形，有正负极）
2. 长腿是正极（+），短腿是负极（-），外壳上通常有白色条纹标记负极
3. 把电容正极接到灯环的 **5V** 线上
4. 电容负极接到灯环的 **GND** 线上
5. 如果用电烙铁，焊好后套热缩管；如果用面包板，直接插到对应排孔

### Step 3：组装 74AHCT125 电平转换电路

ESP32-S3 输出 3.3V 信号，但 WS2813 灯环需要 5V 信号才稳定。74AHCT125 就是干这个的。

**芯片方向：** 芯片上有个半圆形缺口或圆点，那是第 1 引脚标记。把缺口朝左，引脚向下插在面包板上，左右两排引脚分别插入面包板左右两侧。

接线（所有线都用杜邦线，公对公插面包板）：

| 74AHCT125 引脚 | 连接到哪里 | 说明 |
|---------------|-----------|------|
| 引脚 14 (VCC) | 5V 电源正极 | 芯片供电 |
| 引脚 7 (GND) | 电源地 | 芯片接地 |
| 引脚 1 (1OE) | GND | 使能通道1（低电平有效） |
| 引脚 2 (1A) | 10kΩ 电阻 → GND | 输入下拉，防止悬空 |
| 引脚 2 (1A) | ESP32-S3 GPIO18 | 数据信号输入（3.3V） |
| 引脚 3 (1Y) | 330Ω 电阻 → 灯环 DIN | 数据信号输出（5V） |
| 引脚 4 (2OE) | VCC (5V) | 禁用通道2 |
| 引脚 5 (2A) | GND | 未用通道接地 |
| 引脚 6 (2Y) | 空着不接 | 未用输出悬空 |
| 引脚 8-13 | 空着或按同样方式处理 | 其他未用通道 |

**0.1µF 陶瓷电容**（标称 104）跨接在 74AHCT125 的 VCC（引脚14）和 GND（引脚7）之间，越靠近芯片越好。

### Step 4：连接旋转编码器

编码器有 5 个引脚，用杜邦线（公对母）连接：

**3 引脚那排（旋转功能）：**
| 编码器引脚 | 连接到 | 说明 |
|-----------|--------|------|
| A相（左边） | ESP32-S3 GPIO1 | 旋转信号A |
| Common（中间） | GND | 公共端接地 |
| B相（右边） | ESP32-S3 GPIO2 | 旋转信号B |

**2 引脚那排（按键功能）：**
| 编码器引脚 | 连接到 | 说明 |
|-----------|--------|------|
| 按键脚1 | ESP32-S3 GPIO3 | 按键信号 |
| 按键脚2 | GND | 按键接地 |

> 注意：GPIO 编号是推荐值，实际以固件代码为准。如果固件里定义了其他引脚，按代码来接。

### Step 5：连接 LED 灯环电源

**重要：灯环不用 ESP32-S3 的 5V 引脚供电，用外接电源。**

1. 可调电源调到 **5V**，限流调到 **0.5A（500mA）**
2. 电源正极（红色线）→ 灯环 5V 输入
3. 电源负极（黑色线）→ 灯环 GND
4. 电源负极还要分一根线 → ESP32-S3 的 GND（共地）
5. 电源负极再分一根线 → 74AHCT125 的 GND（共地）

> 所有 GND 必须连在一起，这叫"共地"，是电路正常工作的前提。

### Step 6：连接 ESP32-S3 和电脑

1. 用 USB-C 数据线连接 ESP32-S3 和电脑
2. 此时 ESP32-S3 会通电，屏幕可能会亮（如果已有固件）
3. **但灯环还不亮**，因为还没刷固件

### Step 7：最终检查（上电前必做）

在插电之前，用万用表做以下检查：

1. **测 5V 和 GND 之间**：调到电阻档，表笔分别碰 5V 线和 GND 线，应该显示很大电阻（不短路）
2. **测电容极性**：电解电容长腿接 5V，短腿接 GND，确认没接反
3. **测所有 GND**：任意两个 GND 点之间电阻应该接近 0（导通）
4. **检查 74AHCT125**：VCC 接 5V，GND 接地，没接反
5. **检查编码器**：Common 和按键一端都接了 GND

全部确认无误后，才可以进入下一步。

## 五、上电顺序（严格遵守）

**接线或改线时，所有电源必须断开。**

**上电：**
1. 先开可调电源（5V），确认电压稳定
2. 等 2 秒
3. 再把 USB-C 线插到电脑（ESP32-S3 通电）
4. 等系统识别串口

**下电：**
1. 先拔 USB-C 线（断开 ESP32-S3）
2. 等 2 秒
3. 再关可调电源

## 六、接下来做什么

组装完成后，硬件部分就 ready 了。但灯环还不会亮，因为：

1. 需要给 ESP32-S3 刷入 Codex Halo 固件（`firmware.bin`）
2. 固件需要配置正确的 GPIO 引脚号
3. 桌面软件需要识别串口并建立连接

## 七、常见问题

**Q：灯环不亮？**
- 检查电源是不是 5V，限流是不是太小
- 检查 DIN 线有没有接对（是不是接到了 DOUT）
- 检查 74AHCT125 方向有没有插反

**Q：电脑识别不到 ESP32-S3？**
- 换一根 USB-C 线（确认是数据线）
- 换一个 USB 口
- 检查设备管理器有没有新设备

**Q：编码器转动没反应？**
- 检查 Common 端有没有接地
- 检查 GPIO 引脚号对不对

**Q：灯珠乱闪或颜色不对？**
- 检查 330Ω 电阻有没有接上
- 检查电源限流是不是太小
- 检查有没有共地
